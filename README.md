# Teleport-Chips-Expression-2
This is the 4th version of my teleport chip. Written in expression 2 for garry's mod.

# How to use/install Expressions
1. You need to own Garry's Mod
2. you need Wiremod installed: https://steamcommunity.com/sharedfiles/filedetails/?id=160250458
3. Go to "manage" in Garry's mod in the steam library
4. Click "Browse local files"
5. Open "garrysmod" > "data" > "expression2"
6. Move file there
7. In game you should now be able to open it, place it, and enjoy!
